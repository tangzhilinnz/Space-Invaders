# C# Design-Patterns (Space Invaders)
A C# implementation of the classic arcade game Space Invaders, developed using the AZUL framework. This project showcases 15 software design patterns, demonstrating modern software engineering principles such as modular architecture, iterative development, and object-oriented design.

# Key Features:
✅ Faithful recreation of Space Invaders with all core gameplay mechanics

✅ 15 integrated design patterns, including:

Creational: Singleton, Factory

Structural: Flyweight, Proxy, Adapter, Composite

Behavioral: Observer, Command, Iterator, State, Strategy, Visitor, Object Pool, Null Object, Template

✅ Well-structured game systems: Input, Animation, Collision, Sound, Display

✅ Designed for scalability and maintainability
